# Design assets: what's current, what's retired, where it lives

The map of this site's visual assets. Current comes first. Retired assets are labeled with a date and a reason and kept, so they can come back. The map for all three Adapt To Life sites (adapttolife.org, this site, and adaptbodyshop.com) is `brand/README.md` in `adapttolife/adapt-to-life`.

## Current

| Asset | Where | Notes |
|---|---|---|
| Sport drawings | `public/emblems/sports/` | Alec's flat vector drawings, one per sport. Drive is the source; `scripts/sport-icons-sync.py` is the only way in (see that folder's README). |
| Sport drawings in motion | `public/emblems/motion/` | Each drawing plays its sport's move. Built by `scripts/motion/build.py`. |
| Grant, event and adaptive badges | `public/emblems/*.png`, `public/emblems/adaptive.svg` | |
| Scenes | `public/scenes/` | Place photographs behind listings (a gym, a court, a road). |
| Photographs | `public/assets/photos/` | |
| Share image | `public/assets/og-coaching.jpg` | |
| UI icons | `public/app/icons.js` | A Lucide subset, generated by `scripts/build-app-icons.mjs`. adapttolife.org has moved to a shared symbol dictionary (Phosphor, Material Symbols, Simple Icons); moving this site onto it is a separate change. |
| Logo | Adapt To Life's official mark, carried over in PR #44 | The source is `brand/` in `adapttolife/adapt-to-life`. |

`public/listing-art.js` is the one place the site picks a sport, grant or event image. Nothing else points at image files by name.
