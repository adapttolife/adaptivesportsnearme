# Icons and logos

Where every icon and logo on the site lives, and which ones are retired. If you need a
sport icon or the logo for anything (the site, a flyer, a social post), take it from the
current paths below.

This is the one map for this site. The map across all three Adapt To Life sites
(adapttolife.org, this site and adaptbodyshop.com) is `brand/README.md` in
`adapttolife/adapt-to-life`.

## Current

| What | Where | Source and how to update |
|---|---|---|
| Sport icons | `public/emblems/sports/<key>.svg` (+ `.png`, 512 px) | Alec's drawings. Source of truth is Google Drive, Website / ASNM Flat Vector Logo / SVGs. One file per sport key, plus `multi`, `grant` and `event`. Update with `scripts/sport-icons-sync.py`; the steps and the key to Drive file table are in [public/emblems/sports/README.md](../public/emblems/sports/README.md). |
| Sport icons in motion | `public/emblems/motion/*.json` | Built from the icons by `scripts/motion/build.py`. See [scripts/motion/README.md](../scripts/motion/README.md). |
| Share cards | `public/og/` (`sports/`, `states/`, home, events, grants) | Built by `scripts/og/build.mjs`. |
| Adapt To Life logo (official) | `scripts/icons/brand/090226_AdaptToLife_Icon.svg` (mark), `090226_AdaptToLife_Primary.svg` (full logo) | Brand identity of 2 Sep 2026, Drive: Logos / FINAL Logo. Charcoal `#3B3B46`, coral `#FF5C39`. |
| Logo on the site | `public/app/logo.svg`, `public/app/logo-cream.svg` (dark mode) | The official mark. |
| Favicon and app icons | `public/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Built from the official mark by `scripts/icons/brand.py`. |
| Generic listing stamp | `public/emblems/adaptive.svg` | Built by `scripts/icons/brand.py`. Used when a listing has no sport. |
| Scenes | `public/scenes/` | Place photographs behind listings (a gym, a court, a road). |
| Photographs | `public/assets/photos/` | |
| Share image | `public/assets/og-coaching.jpg` | |
| UI icons | `public/app/icons.js` | A Lucide subset, generated by `scripts/build-app-icons.mjs`. adapttolife.org has moved to a shared symbol dictionary (Phosphor, Material Symbols, Simple Icons); moving this site onto it is a separate change. |

`public/listing-art.js` is the one place the site picks a sport, grant or event image. Nothing else points at image files by name.

The scripts behind all of these are described in [scripts/icons/README.md](../scripts/icons/README.md).

## Archive

Retired sets live in `archive/`, outside `public/`, so the site no longer serves them.
They are kept for the record, not for use.

| Folder | What it was | Why it was retired |
|---|---|---|
| `archive/icons/3d-sport-chairs/` | 3D renders of a sports wheelchair with each sport's gear (11 sports), the category chips on the August 2026 site | Replaced by Alec's drawings in October 2026. Nothing on the site loads them. Retired 29 Oct 2026; history and how to bring them back in the [README there](../archive/icons/3d-sport-chairs/README.md). |
| `archive/icons/emblem-pngs/` | The earlier emblem set (17 sports, plus grant and event art) once served from `public/emblems/*.png` | Replaced by `public/emblems/sports/` on 14 Oct 2026. Only an unused helper still pointed at them. |
| `archive/sport-photos/` | Photoreal sport images for the launch sports | Moved out of use by Alec on 13 Oct 2026 (launch on symbols). |

The old Adapt To Life drawing (`atl-logo-2026`, 31 Jul 2026) is retired too. Nothing here
may use it, and `test/listing-art.test.js` fails if an `atl-logo*` or `athlete*.svg` file
comes back into `public/emblems/`.

## Old copies elsewhere

Other repos and folders still hold earlier sets. Don't take icons from them:

- `adapttolife/adapt-to-life`, `brand/atl-logo*`: the retired Jul 31 Adapt To Life drawing.
- Branches cut before 14 Oct 2026 may still carry `public/emblems/athlete-*.svg`: the
  athlete series drawn from the retired logo.
- `adapttolife/adaptivesportsnearme-data`, `drop/ASNM v1.html`: line glyphs from an early
  design mock-up.
